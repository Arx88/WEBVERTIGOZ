# Avatares genéricos

Esta carpeta contiene las 12 siluetas medievales auto-asignadas a los jugadores al inscribirse.

## Lista

- knight.svg
- archer.svg
- monk.svg
- scout.svg
- berserker.svg
- cataphract.svg
- huskarl.svg
- mameluke.svg
- teutonic-knight.svg
- samurai.svg
- war-elephant.svg
- longbowman.svg

## Estilo

- SVG vectorial
- Stroke blanco `#FFF8E7` 1.5px
- Sin relleno
- Tamaño 256x256px
- Fondo transparente

## Asignación

Cuando un jugador se inscribe, se le asigna uno de estos 12 avatares aleatoriamente. La asignación se guarda en `account.avatar_key`.
