# Emblemas

Esta carpeta contendrá los 50+ escudos que los equipos podrán elegir al inscribirse.

## Subida

Los emblemas se suben desde el panel admin en `/admin/emblemas`. Se guardan en Supabase Storage (bucket `emblems`).

## Especificaciones

- Formato: SVG preferido (PNG con transparencia aceptado)
- Tamaño: 512x512px
- Estilo: escudos heráldicos medievales, premium sobrios (NO cyberpunk)
- Paleta: dorado `#D4AF37`, violeta `#8B2CF5`, blanco roto `#FFF8E7`
